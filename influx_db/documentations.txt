This folder manages connections and configurations related to InfluxDB, the time-series database.

Files and their contents:

1. connection.py
Classes:
- InfluxDBService: A service class for interacting with InfluxDB.
  - getClient(): Authenticates and returns an `InfluxDBClient` instance using environment variables.
  - getWriteApiSync(client): Returns a synchronous write API object for writing points.
  - getQueryApi(client): Returns a query API object for querying using Flux.
  - getOrg(): Retrieves the configured InfluxDB organization.
  - getBucket(): Retrieves the configured InfluxDB bucket.

2. const.py
- Defines string constants for tags, fields, measurements (e.g., metric_numeric_1m, metric_numeric_10m), and source metadata names used throughout the InfluxDB storage processes.

Operational notes:
- The test suite uses SQLite and does not hit InfluxDB; provide valid `INFLUX_URL`, `INFLUX_TOKEN`, `INFLUX_ORG`, and `INFLUX_BUCKET` to run rollups or writes.
- Rollup jobs expect PostgreSQL for their source aggregates (`date_trunc` usage) and will not work against SQLite.
